# Asset Credits and Provenance

This inventory records what can be verified from the current website files and their embedded metadata. It is not a legal determination or confirmation that any asset is cleared for commercial use.

## Quran data and audio

- The site requests surah data from the EQuran API v2 endpoint (`https://equran.id/api/v2`). The API is an identified runtime source; its availability and terms can change. No license grant for the API content or audio is recorded in this project.
- The local JSON files in `assets/data/` provide offline fallback data. Their records include Arabic text, Indonesian translations, and audio URLs. Some tafsir records identify their source as the Quran application of the Indonesian Ministry of Religious Affairs, but the project does not record a complete provenance or license for every text field.
- Audio URLs embedded in the JSON point to `download.quranicaudio.com`. A hosting URL alone does not establish copyright ownership, permission to redistribute, or commercial-use rights. Those rights remain unverified.

## Font
